# 组织成员与维护者

Cyrene-Agent 由个人发起，背后没有公司，也没有商业团队。仓库的日常运转——issue 分诊、PR 审查、构建与发布验证、渠道适配回归、社群答疑、文档校对——由下面这些人在业余时间里无偿承担。

> **以下排名不分先后**，分组只是为了说明角色，不代表轻重。

## 感谢

维护一个长期迭代的桌面 Agent 并不轻松。它不是写完就放着的项目：每一次发版背后，都有深夜的构建、只在某个 Windows 版本上才复现的崩溃、以及大量不会出现在 changelog 里的问询和排查。

这些事情没有报酬，也很少被人看见，但它们决定了这个项目还能不能继续走下去。谢谢你们愿意把业余时间花在这里。

—— Playa
